# NE-PE-X 개조 차량 인계 체크

개조업체가 차량별 설치 항목을 **설치 → 설치 확인 → 재확인(컨펌)** 3단계로 기록하고, 필수 항목이 모두 컨펌된 차량만 우리 팀이 인수하는 웹페이지.

## 실행

Python 3.9+ 표준 라이브러리만 사용 (추가 설치 없음).

```bash
python3 app.py --host 0.0.0.0 --port 8000
```

- 접속: `http://<서버주소>:8000`
- 데이터: 같은 폴더의 `handover.db` (SQLite, `--db` 로 경로 변경). 백업은 이 파일을 복사하면 됨.
- 테스트: `python3 -m unittest -v test_app`

## 규칙

- 체크 항목(차량당 25개): 카메라 1~8, 라이다 1~8, Thor(설치·로깅 시스템·알고리즘 동작·센서 연결), Orin(설치·뷰어·로깅 애플리케이션·업로더·관제 시스템)
- 관제 시스템은 기록만 하고 인수 필수 조건에서 제외
- 같은 항목에서 설치자·확인자·컨펌자는 서로 달라야 함
- 불합격은 사유 필수, '보완 필요'로 돌아가 재설치부터 다시 진행. 이력은 누적(덮어쓰기 없음)
- 필수 24개가 모두 컨펌되어야 '우리 팀 인수 완료' 가능. 인수 후에는 수정 불가

## 제한 사항 (v1)

- 로그인 없음: 상단에 입력한 이름으로 기록. 사내망 안에서만 운영 전제
- 증빙은 메모(텍스트)만 가능, 사진·로그 파일 첨부 없음
